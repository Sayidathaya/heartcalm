## 🎯 Ringkasan Proyek

**HEARTCALM Acne Water Gel** adalah produk skincare untuk kulit berjerawat dengan tekstur *water gel* yang ringan dan menyegarkan. Repositori ini berisi **landing page statis** — satu halaman yang berfungsi sebagai etalase digital produk tersebut.

Bayangkan sebuah etalase toko yang selalu terbuka, tidak perlu tutup, dan bisa diakses dari mana saja tanpa biaya server.

> [!NOTE]
> Proyek ini **tidak memakai framework backend, tidak ada database, dan tidak ada proses build**. Seluruh halaman dirakit dari HTML, CSS, dan JavaScript murni, lalu disajikan apa adanya oleh GitHub Pages. Konsekuensinya: biaya hosting **Rp 0**, waktu muat sangat cepat, dan tidak ada yang bisa rusak karena server.

## ❓ Masalah yang Diselesaikan

Kulit berjerawat punya masalah yang berlawanan: moisturizer yang terlalu tebal bikin breakout, tapi yang terlalu ringan bikin kulit kering dan iritasi. HEARTCALM menjawabnya dengan formula *water gel*.

| 😵 Sebelum | 😎 Dengan HEARTCALM |
|---|---|
| Moisturizer tebal menyumbat pori dan memperparah breakout | Tekstur *water gel* yang ringan, cepat meresap, dan tidak menyumbat pori |
| Jerawat meradang terasa perih dan panas | **Cooling sensation** langsung menenangkan area yang irritated |
| Produksi minyak berlebih membuat wajah mengkilap | Formulasi membantu mengontrol produksi minyak |
| Sulit menemukan moisturizer yang cocok untuk kulit sensitif | Aman untuk semua jenis kulit, termasuk acne-prone |
| Website produk berat, lambat, dan mahal di-host | **100% statis**, dimuat dalam hitungan milidetik, gratis selamanya |

## ✨ Fitur Utama

### 🧴 1. Hero Section dengan Cooling Sensation

Bagian pertama yang langsung menangkap perhatian. Menjelaskan produk dalam satu kalimat, diperkuat dengan badge yang memancing klik, dan dua tombol ajakan bertindak (CTA): *Beli Sekarang* dan *Konsultasi Admin*.

### 📖 2. Bagian Bahan (Ingredients)

Menampilkan komposisi utama produk dalam bentuk kartu yang mudah dipindai mata:

| Bahan | Fungsi |
|---|---|
| **5% Panthenol** | Menenangkan kulit berjerawat dan merawat kulit kemerahan/sensitif |
| **5X Ceramide** | Memperkuat skin barrier |
| **Compound Ectoin** | Merawat dan menghidrasi kulit |
| **Pure Centella** | Meredakan dan menenangkan irritated skin |

Dilengkapi daftar lengkap INCI dalam bentuk chip, plus bagian *hero ingredients* interaktif.

### 💧 3. Manfaat Utama

Tiga kartu manfaat yang dikemas dengan baik:

- **Merawat Jerawat** — membantu menenangkan breakout yang sedang meradang
- **Merawat Kemerahan** — mengurangi kemerahan pada kulit sensitif
- **Menjaga Higienis** — menjaga kulit tetap sehat dan seimbang

### 🔍 4. Permasalahan Kulit (Carousel)

Bagian interaktif yang memutar lima masalah kulit — **Jerawat, Gatal, Kemerahan, Sensitif** — lengkap dengan penjelasan dan solusi yang sesuai untuk tiap masalah.

### 📈 5. Hasil Penggunaan

Visualisasi hasil berupa **ring chart (`conic-gradient`)** yang menampilkan persentase perbaikan, lengkap dengan animasi dan catatan sumber data yang jujur (self-assessment 30 responden, usia 18–30 tahun, 1 minggu pemakaian).

### 💬 6. Testimoni

Empat testimoni dengan avatar, rating bintang, dan nama pelanggan — plus marquee/scroller untuk navigasi.

### 📬 7. Form Newsletter

Form email dengan **validasi bawaan HTML5** (`type="email"` + `pattern`) dan tampilan modal konfirmasi. Diarsipkan sebagai simulasi antarmuka — data tidak dikirim ke server mana pun.

### 🔗 8. Navigasi & Footer Lengkap

Navbar *sticky* dengan efek kaca (*glassmorphism*), scrollspy otomatis, tombol social media (TikTok, Instagram, Facebook, YouTube, X), link toko resmi (Shopee, TikTok Shop), dan tautan WhatsApp.

## 🎨 Sistem Desain

### 🎨 Palet Warna

Semua warna didefinisikan sebagai **CSS Custom Properties** di `css/style.css`, sehingga mudah diganti dari satu tempat.

| Token | Nilai | Dipakai Untuk |
|---|---|---|
| `--aqua` | `#e53935` | Warna utama (merah brand) |
| `--aqua-dark` | `#b71c1c` | Teks/heading kontras |
| `--aqua-light` | `#ffccbc` | Aksen lembut |
| `--ink` | `#0d2b34` | Warna teks utama |
| `--paper` | `#fdfdfd` | Latar halaman |
| `--sun` | `#e53935` | Aksen menyala |
| `--grad` | `linear-gradient(135deg, #e53935, #ff8a80)` | Gradasi tombol & judul |

### ✨ Fitur Visual

- **Glassmorphism** — navbar dengan `backdrop-filter: blur(14px)` dan latar transparan
- **Scroll reveal** — elemen muncul halus saat masuk viewport (diaktifkan lewat kelas `.js`)
- **Progress bar** — indikator progres scroll di sisi atas
- **Gelembung air** — dekorasi gelembung naik perlahan sesuai tema "water gel"
- **Ring chart** — visualisasi hasil penggunaan memakai `conic-gradient` murni CSS
- **Wave divider** — pemisah bergelombang antar section

### 📐 Prinsip Responsive

| Ukuran | Perilaku |
|---|---|
| **Desktop (> 992px)** | Navbar penuh, grid 2 kolom pada hero, section melebar |
| **Tablet (768–992px)** | Navbar berubah ke tombol hamburger, grid adapts |
| **Mobile (< 768px)** | Semua section menjadi satu kolom, font menyesuaikan via `clamp()` |

> [!NOTE]
> Ukuran font besar memakai `clamp(min, preferred, max)` — misalnya `font-size: clamp(1.7rem, 4vw, 2.6rem)`. Dengan begitu ukuran judul menyesuaikan lebar layar secara otomatis tanpa perlu menulis banyak breakpoint manual.

## 🚀 Menjalankan Secara Lokal

Tidak ada yang perlu di-install. Cukup buka `index.html` di browser.

### 🖥️ Opsi 1 — Buka Langsung

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 🌐 Opsi 2 — Live Server (disarankan)

```bash
npx serve .
```

Lalu buka `http://localhost:3000`.

### ⚠️ Catatan Penting

Semua path aset menggunakan path relatif (`./css/...`, `./asset/...`), **bukan** path absolut (`/css/...`). Inilah alasannya:

| Deploy di | Path Aset | Hasil |
|---|---|---|
| Sub-folder repo (`/heartcalm/`) | `./css/style.css` | ✅ Aman |
| Root domain (`/`) | `./css/style.css` | ✅ Aman |
| Dibuka via `file://` lokal | `./css/style.css` | ✅ Aman |

### 🧩 Kenapa Tidak Ada Build Step?

Karena tidak ada proses kompilasi yang perlu dijalankan:

```text
   SEBELUM (umum)          SETELAH (proyek ini)
   ─────────────           ────────────────────
   source code              index.html  ──┐
   + npm install            css/         ──┤
   + npm run build          js/          ──┼──>  git push  ──>  GitHub Pages
   + upload dist/           library/     ──┤
   + konfigurasi server     .nojekyll    ──┘
```

> [!IMPORTANT]
> Berkas **`.nojekyll`** di root repo itu wajib ada. Tanpa itu, GitHub Pages menjalankan Jekyll sebagai proses build dan akan **mengabaikan** folder atau berkas yang namanya diawali `_` atau `assets`, sehingga situs bisa tampil tanpa gambar.

## 📖 Kamus Istilah untuk Pemula
